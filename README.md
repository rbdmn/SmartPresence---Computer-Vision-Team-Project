# SmartCampus Presence

I positioned to be a Backend Developer and this is my role on this project:
- Designed and implemented a NoSQL database architecture using MongoDB Atlas to ensure scalable and globally accessible student attendance data storage.
- Modeled data structures and collection relationships to optimize data integrity and query performance for facial recognition systems.
- Developed high-performance RESTful APIs using FastAPI to facilitate real-time data communication between Computer Vision models and the user interface.

## SETUP:  
- py -m venv env (create env) 
- env\Scripts\activate (activate env) 
- pip install -r requirements.txt (install libraries)

## HOW TO RUN:
- env\Scripts\activate  
- uvicorn main:app --reload
- 127.0.0.1:8000/docs (for Swagger in FAST API)
